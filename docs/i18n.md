# Languages

The site is available in English, Spanish (`es`), Chinese Simplified (`zh`) and
Hindi (`hi`). English lives at the root (`/about`); every other language has its
own prefix (`/es/about`).

## How a visitor gets a language

`src/proxy.ts` decides, for any URL without a language prefix:

1. The visitor's saved choice (cookie `coi-lang`, set by the language switcher).
2. Otherwise the browser's ranked language list. The first language we offer wins.
   Someone who ranks English first stays on English.
3. Otherwise their country (CDN header: `x-vercel-ip-country`, `cf-ipcountry`,
   `cloudfront-viewer-country`). The country list is `COUNTRY_DEFAULTS` in
   `src/i18n/detect.ts`.
4. Otherwise English.

Search engines and link-preview bots always get English and never a redirect.
Every translation is cross-linked with `hreflang` and listed in the sitemap.

## The YouTube video

Each language page asks the player for its interface language (`hl`) and for
captions in that language (`cc_lang_pref`, `cc_load_policy=1`). Captions appear
when the video has them, including YouTube's automatic translation.

**To use a real dubbed or translated upload**, add it in `src/lib/episode-data.ts`:

```ts
"penicillin": {
  videoId: "zbeBT46ymp4",
  videoIds: { es: "NEW_SPANISH_VIDEO_ID", hi: "NEW_HINDI_VIDEO_ID" },
  ...
}
```

That language then plays its own video on the episode page, the home hero,
the structured data and the share metadata. No other change is needed.

## Where the words live

All text is in `src/i18n/messages/{en,es,zh,hi}.json`. `en.json` is the source;
the other files must have exactly the same keys (a missing key fails the
TypeScript build). Small markup inside strings:

- `<em>word</em>` gold italic accent
- `<i>word</i>` plain italic
- `|` optional line break on wide screens
- `{n}`, `{year}` placeholders

## Adding a language

1. Add it to `locales` and `localeMeta` in `src/i18n/config.ts`.
2. Add `src/i18n/messages/<code>.json` and import it in `src/i18n/messages.ts`.
3. Optionally add countries to `COUNTRY_DEFAULTS`.
4. If the script needs a font, add it in `src/app/[lang]/layout.tsx`.

## Adding an episode

Add its facts to `src/lib/episode-data.ts` and `src/lib/episodes.ts`, and its
text under `episodes.<slug>` in all four message files.

## Legal pages

Privacy and Terms are translated for the page chrome only. The long legal text
is still English, with a notice in the other languages saying the English text
prevails. Have counsel review before translating the body.
